# MiniUspev

Система учета успеваемости и посещаемости студентов на Laravel 9 + SQLite + Bootstrap + JavaScript/AJAX.

## Основные возможности

- авторизация и роли `Администратор`, `Преподаватель`, `Студент`;
- группы, студенты и дисциплины;
- электронный журнал посещаемости и оценок;
- домашние задания со сканами/PDF, проверкой, оценкой и доработкой;
- личный кабинет студента;
- отчеты и CSV для Excel;
- уведомления студентов и преподавателей;
- управление студенческими учетными записями.

## Учебные годы и семестры

Добавлена сущность учебного периода. Администратор может создавать периоды вида `2026/2027 · 1 семестр`, задавать даты начала/окончания и выбирать один активный семестр.

Активный семестр автоматически используется при создании нового занятия, если преподаватель не выбрал другой период. В журнале можно фильтровать занятия по семестру.

## Типы работ и вес оценок

Администратор управляет типами работ. После `php artisan db:seed` создаются:

- Ответ на занятии — вес 1.0;
- Домашняя работа — вес 1.0;
- Лабораторная работа — вес 1.5;
- Самостоятельная работа — вес 1.5;
- Контрольная работа — вес 2.0;
- Зачёт — вес 2.5;
- Экзамен — вес 3.0.

При создании занятия преподаватель выбирает тип работы. Его стандартный вес автоматически подставляется в форму, но может быть изменен вручную от 0.1 до 10.

Взвешенный средний считается по формуле:

`Σ(оценка × вес) / Σ(вес)`

Оценки из журнала и проверенных домашних заданий могут участвовать в семестровом расчете.

## Итоговые оценки

Раздел `Итоги` позволяет преподавателю выбрать семестр, группу и дисциплину. Для каждого студента система рассчитывает взвешенный средний балл. Преподаватель может утвердить итоговую оценку `2–5` и оставить комментарий.

Сохраняются отдельно:

- рассчитанный системой балл;
- утвержденная итоговая оценка;
- комментарий;
- пользователь, который установил итог.

## Домашние задания

- задание по группе и дисциплине;
- дедлайн;
- до 10 файлов JPG/JPEG/PNG/WEBP/PDF по 10 МБ;
- закрытое хранение файлов;
- повторная отправка;
- проверка преподавателем;
- оценка 2–5;
- комментарий;
- возврат на доработку.

## Личный кабинет студента

После входа студент попадает на `/student/dashboard`. Там отображаются средний балл, посещаемость, прогулы, задолженности, показатели по дисциплинам, ближайшие дедлайны, история ДЗ и последние записи журнала.

## Уведомления

Студент получает уведомления о новых ДЗ, дедлайнах, оценках, возврате на доработку и изменениях посещаемости. Преподаватель получает уведомления о сдаче/пересдаче ДЗ, просрочках и студентах группы риска.

## Установка

```bash
composer install
cp .env.example .env
php artisan key:generate
mkdir -p database
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

Открыть: http://127.0.0.1:8000
