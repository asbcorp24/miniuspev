# MiniUspev

Система учета успеваемости и посещаемости студентов на Laravel 9 + SQLite + Bootstrap + JavaScript/AJAX.

## Возможности

- авторизация;
- роли `Администратор` и `Преподаватель`;
- привязка преподавателей к группам и дисциплинам;
- группы и студенты;
- дисциплины;
- занятия по датам;
- посещаемость: присутствовал / отсутствовал / опоздал / уважительная причина;
- оценки 2–5;
- комментарий преподавателя;
- средний балл студента;
- процент посещаемости;
- электронный журнал группы по дисциплине;
- AJAX-сохранение оценок и посещаемости;
- карточка студента;
- подсчет прогулов и задолженностей;
- сводная ведомость по группе;
- выгрузка CSV для Excel;
- сводный дашборд.

## Установка

```bash
composer install
cp .env.example .env
php artisan key:generate
mkdir -p database
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

Открыть: http://127.0.0.1:8000

## Тестовые учетные записи

Администратор:
- Email: `admin@example.com`
- Пароль: `password`

Преподаватель:
- Email: `teacher@example.com`
- Пароль: `password`

Преподавателю автоматически назначается демонстрационная группа `ССА-21` и дисциплина `Введение в специальность`.

Если база уже была создана предыдущей версией проекта, достаточно выполнить:

```bash
php artisan migrate --seed
```

> Для запуска требуется PHP 8.0.2+, Composer и расширение PDO SQLite.
