# MiniUspev

Система учета успеваемости и посещаемости студентов на Laravel 9 + SQLite + Bootstrap + JavaScript/AJAX.

## Возможности MVP

- группы и студенты;
- дисциплины;
- занятия по датам;
- посещаемость: присутствовал / отсутствовал / опоздал / уважительная причина;
- оценки 2–5;
- комментарий преподавателя;
- средний балл студента;
- процент посещаемости;
- журнал группы по дисциплине;
- быстрый ввод данных без перезагрузки страницы;
- сводный дашборд;
- добавление групп, студентов и дисциплин из интерфейса.

## Установка

```bash
composer install
cp .env.example .env
php artisan key:generate
mkdir -p database
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

Открыть: http://127.0.0.1:8000

После `migrate --seed` будут созданы демонстрационная группа, три студента и две дисциплины.

Текущий MVP рассчитан на кабинет одного преподавателя. Авторизацию, роли преподаватель/администратор и разграничение доступа можно добавить следующим этапом.

> Для первого запуска требуется PHP 8.0.2+, Composer и расширение PDO SQLite.
