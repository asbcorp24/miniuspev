# MiniUspev

Система учета успеваемости и посещаемости студентов на Laravel 9 + SQLite + Bootstrap + JavaScript/AJAX.

## Основные возможности

- авторизация и роли `Администратор`, `Преподаватель`, `Студент`;
- группы, студенты и дисциплины;
- электронный журнал посещаемости и оценок;
- домашние задания со сканами/PDF, проверкой, оценкой и доработкой;
- личный кабинет студента;
- семестровые отчеты и CSV для Excel;
- уведомления студентов и преподавателей;
- управление студенческими учетными записями;
- справки об уважительных пропусках с подтверждением.

## Посещаемость

Новые занятия больше не создают ложную отметку «присутствовал». Для каждого студента создается состояние `unmarked` — «не отмечено».

Состояние `unmarked`:

- не считается присутствием;
- не считается прогулом;
- вообще не входит в расчет процента посещаемости;
- визуально выделяется в журнале серым фоном.

В журнале доступны статусы:

- `—` — не отмечено;
- `П` — присутствовал;
- `Н` — прогул;
- `О` — опоздал;
- `У` — уважительная причина.

Для каждого занятия есть быстрые действия:

- `Все П` — отметить присутствующими только тех студентов, у кого статус еще не заполнен;
- `Сброс` — вернуть всем студентам занятия статус «не отмечено».

Неотмеченные занятия исключаются из сводного дашборда, карточки студента, личного кабинета и семестровых отчетов.

## Справки об уважительных пропусках

Студент может открыть раздел `Справки`, указать период отсутствия, написать комментарий и приложить JPG/JPEG/PNG/WEBP/PDF до 10 МБ.

Документ хранится в закрытом хранилище. Скачать его может только сам студент, администратор или преподаватель, которому доступна группа этого студента.

Статусы справки:

- `На проверке`;
- `Подтверждена`;
- `Отклонена`.

Преподаватель или администратор может оставить комментарий к решению. После подтверждения все реальные отметки `Н` в указанном диапазоне дат автоматически переводятся в `У`.

Если подтверждает преподаватель, автоматически меняются только занятия по доступным ему дисциплинам. Администратор может подтвердить период полностью.

Студент получает уведомление о подтверждении или отклонении справки.

## Учебные годы и семестры

Администратор может создавать периоды вида `2026/2027 · 1 семестр`, задавать даты начала/окончания и выбирать активный семестр.

Семестр используется в журнале, домашних заданиях, личном кабинете студента, итоговых оценках и отчетах. Старые записи без периода продолжают храниться и не удаляются.

## Типы работ и вес оценок

После `php artisan db:seed` создаются стандартные типы:

- Ответ на занятии — 1.0;
- Домашняя работа — 1.0;
- Лабораторная работа — 1.5;
- Самостоятельная работа — 1.5;
- Контрольная работа — 2.0;
- Зачёт — 2.5;
- Экзамен — 3.0.

При создании занятия или ДЗ преподаватель выбирает тип работы. Вес подставляется автоматически и может быть изменен вручную от 0.1 до 10.

Формула семестрового балла:

`Σ(оценка × вес) / Σ(вес)`

В расчете участвуют оценки из журнала и проверенные домашние задания выбранного семестра.

## Итоговые оценки

Раздел `Итоги` позволяет выбрать семестр, группу и дисциплину. Система показывает расчетный взвешенный балл, после чего преподаватель утверждает итоговую оценку `2–5` и при необходимости пишет комментарий.

Студент сразу получает уведомление о выставленной или измененной итоговой оценке. В его личном кабинете итог отображается отдельно от расчетного среднего.

## Домашние задания

- привязка к семестру;
- тип работы и вес;
- задание по группе и дисциплине;
- дедлайн;
- до 10 файлов JPG/JPEG/PNG/WEBP/PDF по 10 МБ;
- закрытое хранение файлов;
- повторная отправка;
- проверка преподавателем;
- оценка 2–5;
- комментарий;
- возврат на доработку.

## Личный кабинет студента

После входа студент попадает на `/student/dashboard`.

Он может переключать семестры и видеть:

- взвешенный средний балл;
- итоговую оценку по каждой дисциплине;
- посещаемость и прогулы за выбранный период;
- задолженности;
- обычный средний по журналу;
- средний за домашние задания;
- тип и вес каждой работы;
- ближайшие дедлайны;
- историю сдачи ДЗ;
- последние записи журнала.

## Семестровые отчеты

Раздел `Отчеты` фильтруется по схеме `семестр → группа → дисциплина`.

Ведомость и CSV содержат:

- ФИО студента;
- группу;
- дисциплину;
- учебный период;
- взвешенный балл;
- утвержденную итоговую оценку;
- посещаемость;
- прогулы;
- задолженности, включая двойки за домашние задания.

## История изменения оценок

При изменении оценки сохраняются старое и новое значение, источник оценки, преподаватель, дата/время, причина изменения и комментарий. История ведется для журнала, домашних заданий и итоговых семестровых оценок.

## Уведомления

Студент получает уведомления о новых ДЗ, дедлайнах, оценках, возврате на доработку, изменениях посещаемости, итоговой оценке за семестр и решении по справке. Преподаватель получает уведомления о сдаче/пересдаче ДЗ, просрочках и студентах группы риска.

## Установка

```bash
composer install
cp .env.example .env
php artisan key:generate
mkdir -p database
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

Открыть: http://127.0.0.1:8000
