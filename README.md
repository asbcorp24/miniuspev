# MiniUspev

Система учета успеваемости и посещаемости студентов на Laravel 9 + SQLite + Bootstrap + JavaScript/AJAX.

## Возможности

- авторизация;
- роли `Администратор`, `Преподаватель` и `Студент`;
- привязка преподавателей к группам и дисциплинам;
- группы и студенты;
- дисциплины;
- занятия по датам;
- посещаемость: присутствовал / отсутствовал / опоздал / уважительная причина;
- оценки 2–5;
- комментарий преподавателя;
- электронный журнал группы по дисциплине;
- AJAX-сохранение оценок и посещаемости;
- карточка студента;
- подсчет прогулов и задолженностей;
- сводная ведомость по группе;
- выгрузка CSV для Excel;
- сводный дашборд преподавателя/администратора;
- домашние задания по группе и дисциплине;
- срок сдачи и описание домашнего задания;
- загрузка студентом до 10 сканов/файлов JPG, PNG, WEBP или PDF;
- закрытое хранение файлов с проверкой прав доступа;
- повторная отправка исправленной работы;
- просмотр файлов преподавателем;
- оценка домашней работы по шкале 2–5;
- возврат домашней работы на доработку;
- комментарий преподавателя к работе;
- отображение студенту результата проверки и оценки;
- админ-раздел управления доступом студентов;
- создание логина и пароля одному студенту;
- массовое создание учетных записей для всей группы;
- автоматическая генерация уникальных временных паролей;
- однократный вывод сгенерированных логинов и паролей;
- смена/сброс пароля студента администратором.

## Личный кабинет студента

После входа студент автоматически попадает на `/student/dashboard`.

В кабинете отображаются:

- общий средний балл с учетом обычных оценок и оценок за домашние задания;
- процент посещаемости;
- количество прогулов;
- количество задолженностей;
- успеваемость отдельно по каждой дисциплине;
- средний балл по журналу;
- средний балл за домашние задания;
- посещаемость по каждой дисциплине;
- список задолженностей;
- ближайшие домашние задания и сроки сдачи;
- статус сдачи домашней работы;
- полученная оценка за ДЗ;
- история сданных домашних работ;
- последние оценки, посещаемость и комментарии преподавателя из журнала.

## Уведомления студента

В меню студента отображается счетчик непрочитанных уведомлений. На отдельной странице хранится история событий.

Уведомления создаются при:

- публикации нового домашнего задания для группы;
- приближении дедлайна несданного ДЗ (в пределах 3 дней);
- выставлении оценки за домашнее задание;
- возврате домашней работы на доработку;
- выставлении или изменении оценки в журнале;
- отметке прогула, опоздания или уважительной причины.

## Уведомления преподавателя

В меню преподавателя также есть счетчик непрочитанных уведомлений и отдельная страница `/teacher/notifications`.

Преподаватель получает события, когда:

- студент впервые сдал домашнее задание;
- студент повторно отправил исправленную работу;
- работа отправлена после срока;
- дедлайн прошел, а студент не сдал работу;
- у студента накопилось 3 и более прогулов по назначенной дисциплине;
- у студента накопилось 3 и более оценок `2` по назначенной дисциплине.

Уведомление ведет сразу к домашнему заданию или карточке проблемного студента. Можно отметить одно событие или все уведомления прочитанными.

## Установка

```bash
composer install
cp .env.example .env
php artisan key:generate
mkdir -p database
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

Открыть: http://127.0.0.1:8000

## Тестовые учетные записи

Администратор:
- Email: `admin@example.com`
- Пароль: `password`

Преподаватель:
- Email: `teacher@example.com`
- Пароль: `password`

Студент:
- Email: `student@example.com`
- Пароль: `password`

Преподавателю автоматически назначается демонстрационная группа `ССА-21` и дисциплина `Введение в специальность`. Студенческая учетная запись привязана к студенту `ST-1`.

Если база уже была создана предыдущей версией проекта, выполнить:

```bash
php artisan migrate --seed
php artisan optimize:clear
```

> Для запуска требуется PHP 8.0.2+, Composer и расширение PDO SQLite.
